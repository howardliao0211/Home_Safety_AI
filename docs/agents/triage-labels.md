# Triage labels

Map canonical triage roles to these tracker strings.
For local Markdown issues, write the string in the `Status:` line.

| Role | Tracker string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on the reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill names a triage role, use its tracker string.
Edit the tracker column to change the vocabulary.
